EBO TEACHES MONEY — Ep 02: Flipping (Adobe Animate file)

Stage: 1080 x 1920, 30 fps, 1431 frames (47.7 s)

LAYERS (top to bottom)
  Captions    - editable text in caption pills (Library > Captions)
  Graphics    - titles, lesson cards, the phone listing / chat, the chalkboard numbers:
                editable text + vector shapes (Library > Graphics)
  Props front - props the characters hold: the lamp, rag, phone, cash, sneakers, radio
  Ebo, Christy, Mica, Obuor
              - each plays its animated rig symbol, e.g. Library > Ebo > "Ebo – Ep02".
                Walking and running use your own cycles (cast/cycles), so those keys are
                the cycle's poses; everything else is rotation/position keys plus eye/mouth swaps.
  Props       - lamp, price tags, sneakers, radio, boxes on tables and the lawn: editable
                vector symbols in the hand-drawn style (Library > Props)
  Background  - the sets only (studio, yard sale, thrift store, moving day, the folding
                table) as editable vector symbols, one per set and camera framing
                (Library > Background). Each one is also in backgrounds/ as an .svg file
                you can open in Illustrator or import.

ADD THE VOICE (1 minute)
  1. File > Import > Import to Library... > choose Ebo_Ep02_voice.mp3
  2. Insert a new layer named "Voice", select frame 1
  3. In Properties > Sound, pick Ebo_Ep02_voice.mp3 and set Sync to "Stream"
  The animation is already timed to this file from frame 1.

NOTES
  - Text uses Arial Black / Arial Bold; outlines are Glow filters on the text.
  - In the video the sets are slightly blurred for depth; in Animate they are sharp.
  - Props in the video have a light crayon grain; in Animate they keep the wavy hand-drawn
    outlines but use flat fills.
  - Built by script and checked by re-rendering it outside Animate; please open it
    in Animate and report anything that looks off.
